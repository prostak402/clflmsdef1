# Feed Player: карта безопасных зон overlay UI

## Цель
Определить единые безопасные зоны для overlay-элементов в плеере ленты по основным форматам кадра:

- вертикальный кадр (`9:16`);
- горизонтальный кадр с `letterbox` внутри вертикального контейнера (`16:9`/`21:9` в `9:16` viewport);
- квадратный кадр (`1:1`).

Документ задает:

1. якоря и отступы для ключевых UI-элементов;
2. адаптивное правило сдвига в полосы (`letterbox`/`pillarbox`);
3. запретные зоны перекрытия (центр лица/действия);
4. синхронизацию с токенами `spacing`, `z-index`, `safe-inset`.

---

## 1) Базовые токены и нормализация отступов

### 1.1 Источники токенов
Используем базовые spacing/z-index токены из `src/styles/design-tokens.css`:

- `--space-sm` = `8px`
- `--space-md` = `16px`
- `--space-lg` = `24px`
- `--z-overlay` = `30`
- `--z-modal` = `40`

### 1.2 Safe-inset слой (норматив для feed-player)
Для feed-player вводится нормализованный safe-inset слой (как алиасы поверх platform insets):

- `--safe-inset-top: env(safe-area-inset-top, 0px)`
- `--safe-inset-right: env(safe-area-inset-right, 0px)`
- `--safe-inset-bottom: env(safe-area-inset-bottom, 0px)`
- `--safe-inset-left: env(safe-area-inset-left, 0px)`

Рекомендуемая расчетная формула для абсолютного позиционирования overlay:

- `offset-top = calc(var(--safe-inset-top) + var(--space-md))`
- `offset-right = calc(var(--safe-inset-right) + var(--space-md))`
- `offset-bottom = calc(var(--safe-inset-bottom) + var(--space-md))`
- `offset-left = calc(var(--safe-inset-left) + var(--space-md))`

### 1.3 Слой наложения

- Основные overlay-элементы (`лайк`, `закладки`, `CTA`, `подпись`) размещаются на `z-index: var(--z-overlay)`.
- Временные поповеры/хинты допускаются выше (`--z-modal`), но не должны менять базовые якоря элементов.

---

## 2) Карта безопасных зон по форматам

> Координатная модель: `x/y` в процентах от контейнера видео, где `(0,0)` — левый верхний угол.

### 2.1 Вертикальный кадр (`9:16`)

**Профиль формата:** полос обычно нет, весь UI размещается поверх кадра.

**Зоны:**

- Верхняя служебная зона: `y = 0..12%` (status/meta-safe).
- Центральная критичная зона (запрещенная для ключевого UI): `x = 25..75%`, `y = 28..78%`.
- Нижняя action-зона: `y = 78..100%`.

**Якоря и отступы:**

| Элемент | Якорь | Отступы (через токены) | Примечание |
|---|---|---|---|
| Лайк | `top-right` | `top: offset-top`, `right: offset-right` | В вертикальном стеке action-кнопок справа. |
| Закладки | `top-right` (под лайком) | `top: calc(offset-top + 44px + var(--space-sm))`, `right: offset-right` | Межкнопочный gap = `var(--space-sm)`. |
| Кнопка «Полный фильм» | `bottom-center` | `bottom: offset-bottom`, `left/right: max(offset-left, offset-right)` | Центрировать в нижней зоне, не выше `y=78%`. |
| Название/подпись | `bottom-left` | `left: offset-left`, `right: calc(offset-right + 56px)`, `bottom: calc(offset-bottom + 44px + var(--space-sm))` | Правый reserve под action-колонку. |

---

### 2.2 Горизонтальный кадр с `letterbox` (`16:9`/`21:9` внутри portrait viewport)

**Профиль формата:** появляются верхняя и нижняя полосы, пригодные для миграции UI.

**Зоны:**

- Верхняя `letterbox`-полоса: `y = 0..topBar%`.
- Контентная зона видео: `y = topBar..(100-bottomBar)%`.
- Нижняя `letterbox`-полоса: `y = (100-bottomBar)..100%`.
- Запрещенная зона в контенте: центральный прямоугольник `x = 22..78%`, `y = topBar+20% .. bottomBar-20%` от контентной области.

**Якоря и отступы:**

| Элемент | Приоритетный якорь | fallback-якорь | Отступы | Примечание |
|---|---|---|---|---|
| Лайк | `top-right` в верхней полосе | `top-right` в контенте | `top/right` от `offset-*` | Сначала уводим в полосу. |
| Закладки | `top-right` в верхней полосе под лайком | `top-right` в контенте | `top += 44px + var(--space-sm)` | Сохраняется вертикальный стек. |
| Кнопка «Полный фильм» | `bottom-center` в нижней полосе | `bottom-center` контента | `bottom: offset-bottom` | CTA приоритетно живет в нижней полосе. |
| Название/подпись | `bottom-left` в нижней полосе | `bottom-left` контента | `left/right/bottom` от `offset-*` | Подпись не перекрывает центр действия. |

---

### 2.3 Квадратный кадр (`1:1`)

**Профиль формата:** в portrait-контейнере обычно есть верх/низ свободного пространства; если полосы не выражены — используем нижнюю не-критичную область самого кадра.

**Зоны:**

- Верхняя зона: `y = 0..14%`.
- Критичная зона: `x = 20..80%`, `y = 24..72%`.
- Нижняя action-зона: `y = 72..100%`.

**Якоря и отступы:**

| Элемент | Якорь | Отступы (через токены) | Примечание |
|---|---|---|---|
| Лайк | `top-right` (полоса при наличии) | `top/right: offset-*` | При наличии верхней полосы — перенос в нее. |
| Закладки | `top-right` (под лайком) | `top += 44px + var(--space-sm)` | Тот же стек и gap. |
| Кнопка «Полный фильм» | `bottom-center` | `bottom: offset-bottom` | При наличии нижней полосы — приоритетно туда. |
| Название/подпись | `bottom-left` | `left/right/bottom` от `offset-*` | Правый reserve под action-кнопки. |

## 3) Правило адаптивного смещения (обязательное)

### 3.1 Детектор полос
Считать, что полоса присутствует, если высота свободной области сверху/снизу кадра:

- `>= var(--space-lg)` (24px) **или**
- `>= 4%` высоты контейнера,

в зависимости от того, что больше.

### 3.2 Правило размещения

1. **Если есть верх/низ полосы:**
   - `лайк`/`закладки` сначала размещаются в верхней полосе;
   - `CTA` и `подпись` сначала размещаются в нижней полосе;
   - только при нехватке места элементы частично возвращаются в край контентной зоны.

2. **Если полос нет:**
   - UI размещается внутри «не-критичной» зоны кадра:
     - верхние углы для secondary-actions;
     - нижняя треть/нижние углы для `CTA` и подписи;
   - центральная зона действия всегда остается свободной.

### 3.3 Приоритеты перепаковки
При конфликте места порядок сохранения якорей:

1. `CTA «Полный фильм»`
2. `Название/подпись`
3. `Лайк`
4. `Закладки`

Менять якорь разрешено только вниз по приоритету.

---

## 4) Запреты и охранные эвристики

### 4.1 Запрет перекрытия центра лица/действия
UI **не должен** перекрывать эвристическую критичную область:

- центр кадра: `x = 30..70%`, `y = 30..70%`;
- плюс нижняя треть действия: `x = 20..80%`, `y = 66..90%` (там часто руки/объекты/саб-экшн).

Если элемент пересекает одну из зон выше, он обязан быть смещен в ближайший доступный угол/полосу.

### 4.2 Дополнительные запреты

- Нельзя одновременно размещать `CTA` и подпись поверх центральных 40% ширины и 40% высоты кадра.
- Нельзя размещать action-колонку (`лайк`, `закладки`) в области `x < 12%` или `x > 88%` без safe-inset поправки.
- Нельзя понижать `z-index` overlay ниже `--z-overlay`, чтобы UI не терял кликабельность на динамичных постерах.

---

## 5) Чеклист синхронизации с токенами

Перед релизом/правками проверять:

- Используются только токены spacing (`--space-sm/md/lg`) для базовых отступов.
- Safe-area считается через `safe-inset` алиасы и участвует в каждом абсолютном смещении.
- Базовый слой overlay = `--z-overlay`; временные панели выше, но без изменения якорей.
- Для `letterbox`-сценариев включено приоритетное переселение UI в полосы.
- Эвристические запретные зоны (центр + нижняя треть действия) не перекрываются ключевыми элементами.
